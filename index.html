계정에 저장하지 못했어요. 인터넷 연결을 확인해 주세요.

로그인

이 사이트 전용 비밀번호를 새로 만드세요. 인하포털 비밀번호와 다르게 해주세요. 지금은 비밀번호 찾기가 없으니 잊지 않게 적어두세요.

참여한 프로그램을 체크하면 예상 마일리지를 바로 볼 수 있어요. 공식 기록은 아니에요.

0이 학기 예상 마일리지
0 / 36참인재 인증 마일리지 (전체 학기)
0 / 12참인재 인증 프로그램 수 (전체 학기)

마일리지는 프로그램이 끝난 날 기준이에요 (1학기: 1~6월, 2학기: 7~12월 종료). 장학금 점수는 마일리지 + 가산점 + 결과보고서(최대 30점)이고, 최근 두 학기는 약 51점부터 장학금을 받았어요.

프로그램

    학교 공식 서비스가 아니에요. 자료는 「2026 인하 더 배움(비교과) 프로그램 가이드북」(교육기획팀)을 옮긴 것이고, 가이드북은 연간 계획이라 실제 일정과 마일리지는 달라질 수 있어요. 확정 마일리지는 인하포털 → 학사행정 → 비교과과정에서 확인하세요 (종료 후 3주 안에 입력돼요).

    로그인하지 않으면 체크한 내용은 이 브라우저에만 저장돼요. 로그인하면 계정에 저장돼서 다른 기기에서도 보여요.
